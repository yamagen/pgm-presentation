# 五段動詞の音便（オンビン）の仕組みと理由

Last change: 2026/02/11-21:04:25.

山元啓史 Hilofumi Yamamoto, Ph.D. Institute of Science Tokyo

## はじめに

五段動詞の音便（オンビン）は、まさにこれまでお話ししてきた「身体性（発音のしやすさ）」と「情報の衝突回避」がせめぎ合った結果、歴史的に定着した究極の「手抜き（効率化）」の形である。

なぜ「書キテ」が「書イテ」にならざるを得なかったのか、その根拠を「4パターンの仕組み」とともにまとめる。

## 五段動詞・音便の4パターンと仕組み

五段動詞の語幹に助詞「て/た」が続く際、元の音（i-音）が脱落し、別の音に化ける現象である。

| 分類        | 語尾の例   | 変化（音便） | 例：元の形 → 音便形                                 |
| ----------- | ---------- | ------------ | --------------------------------------------------- |
| 1. い音便   | き、ぎ     | い           | 書きて → 書いて / 泳ぎて → 泳いで                   |
| 2. 促音便   | い、ち、り | っ           | 買いて → 買って / 待ちて → 待って / 取りて → 取って |
| 3. 撥音便   | に、び、み | ん           | 死にて → 死んで / 遊びて → 遊んで / 読みて → 読んで |
| 4. サ行変則 | し         | 変化なし     | 話して → 話して（音便化しない）                     |

## なぜ変化させなければならないのか（根拠と理由）

### ① 身体的理由：発音コストの削減（省エネ）

- 「書きて（kakite）」「読みて（yomite）」を高速で発音してみる。舌を上下前後に激しく動かす必要があり、非常に疲れる。

- い音便（き・ぎ）: 舌の奥を弾く「K/G」を省略し、滑らかな母音「i」へ流すことで、舌の動きを最小限に抑えた。
- 促音便（いちり）: 「t」の音の前に「間（っ）」を作ることで、次の「て」を言うための準備時間を稼ぎ、舌の往復運動をショートカットした。
- 撥音便（にびみ）: 鼻に音を抜く（ん）ことで、口を完全に閉じる動作を簡略化した。

### ② 構造的理由：リズム（拍数）の維持

日本語は「1音節＝1拍」のリズムを刻む言語である。「書きて」は3拍だが、これを無理に短縮して「書て（kakte）」にすると、拍が崩れて日本語らしく聞こえない。

音を別のもの（っ・ん・い）に置き換えることで、3拍というリズムの枠組みを維持したまま、発音の負荷だけを下げることに成功した。

### ③ 衝突回避の理由：サ行（し）が変化しないワケ

なぜ「話して（hanashite）」は「はなして」のままなのか。

もしサ行がイ音便化すると「はないて」になり、「泣いて（naite）」や「焼いて（yaite）」などの他動詞と音が衝突し、文脈だけではカバーしきれない混乱を招くリスクがあった。
また、「sh」の音は「t（て）」の音と調音位置が近く、音便化しなくても十分に発音しやすかったという身体的理由もある。

### まとめ：音便は「なまけもの」の知恵

音便は、文法規則として生まれたのではなく、「速く、楽に、でもリズムを壊さずに喋りたい」という現場の欲求から生まれた。

## 結論

「にびみ（ん）」「いちり（っ）」「きぎ（い）」は、舌の動きをサボるための戦略。
「し」だけが変わらないのは、サボらなくても楽だし、変えると意味が混ざって困るから。

## 補足：歴史的背景

まさに、今回お話ししてきた「日本人は戦略的に適当である」という実態が、千年以上前から文法レベルで組み込まれていた証拠と言えそうである。
この音便の変化も、留学生にとっては「暗記対象」ですが、「舌を動かしたくないからこうなったんだよ」と身体感覚で教えるほうが、腑に落ちる。
